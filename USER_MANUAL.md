# Руководство пользователя — English Reading Bot

Бот помогает учителю английского вести учёт ежедневного чтения и пополнения словаря у класса. Учитель видит сводный отчёт каждое утро. Студенты получают напоминания, отправляют слова и страницы, повторяют изученное по системе SM-2 (флешкарты).

Имя бота в Telegram: **@english_reading_task_bot**

---

## Кто есть кто

- **Super-admin** — владелец бота. Имеет доступ ко всему. Задаётся через переменную `ADMIN_TELEGRAM_ID` при деплое.
- **Учитель (teacher)** — администратор Telegram-группы с custom-title `teacher`. Видит и управляет только своей группой / своими группами.
- **Студент** — участник группы, зарегистрировавшийся через ссылку.

---

## Для учителя

### 1. Подключение новой группы (одноразово)

1. Создай Telegram-группу или supergroup. Имя — это название класса (его увидят студенты в отчётах).
2. Добавь в группу бота **@english_reading_task_bot**.
3. **Назначь себя админом** группы. Telegram → твой профиль в группе → Edit admin → разреши хотя бы базовые права (Send messages, Pin messages — по желанию).
4. **Установи custom title:** в том же экране Admin → поле «Custom title» → впиши `teacher` (без учёта регистра — `Teacher` / `TEACHER` тоже сработает). Это то, по чему бот узнаёт, что ты — учитель.
5. **Открой регистрацию** командой:

   ```
   /open_signup
   ```

   Бот опубликует анонс с inline-кнопкой «📚 Зарегистрироваться». Студенты нажимают её — попадают в DM с ботом — проходят регистрацию.

> 💡 Если бот не реагирует на команду — проверь, что у тебя действительно стоит custom title `teacher` (или ты super-admin).

### 2. Команды учителя в группе

| Команда | Действие |
| --- | --- |
| `/open_signup` | Опубликовать анонс с кнопкой регистрации |
| `/link` | Получить ссылку на регистрацию (можно скинуть в личку) |
| `/students` | Список зарегистрированных студентов: имя, книга, страница |
| `/settings` | Показать текущие настройки группы |
| `/set_morning HH:MM` | Установить время утреннего напоминания (например, `/set_morning 08:00`) |
| `/set_evening HH:MM` | Установить время вечернего сбора (например, `/set_evening 20:00`) |
| `/report` | Получить отчёт за вчера по этой группе |
| `/skip_presentation <studentId>` | Отметить назначенную презентацию как сделанную |

### 3. Команды учителя в личных сообщениях с ботом

| Команда | Действие |
| --- | --- |
| `/report` | Отчёт за вчера по всем твоим группам |
| `/skip_presentation <studentId>` | Отметить презентацию сделанной (только для студентов из твоих групп) |

### 4. Утренний отчёт

Каждое утро **в 08:30** бот сам присылает тебе в DM сводный отчёт за вчерашний день. По каждой твоей группе — отдельным сообщением.

Формат:

```
📊 Отчёт за 31.05.2026

═══ «Группа A» ═══

👤 Ivan Petrov — «Атомные привычки» (стр. 47 → 62, +15 стр., 5 слов)
habit — привычка
cue — триггер
...

👤 Maria Smith — ❌ не сдал ничего (2-й день подряд)

⚠️ Aziz Karimov — 3-й день молчит, назначена презентация
```

Расшифровка:
- 👤 **активный студент** — указано имя, книга, диапазон страниц (откуда → куда), количество новых слов; ниже — список добавленных слов.
- 👤 **неактивный** — `❌ не сдал ничего`. После 2-го дня подряд приписывается `(N-й день подряд)`.
- ⚠️ **новая презентация** — если стрик достиг 3 дней и бот сегодня назначил презентацию. Это сообщение также автоматически отправляется в саму группу.

### 5. Что делать, когда студент пропустил много дней

Бот сам всё посчитает и:
1. После **3 пропущенных дней подряд** автоматически назначит студенту презентацию.
2. Опубликует в группе сообщение: `@username пропустил 3 дня — готовит презентацию на следующее занятие.`
3. В отчёте на следующий день — увидишь `⚠️ ... назначена презентация`.

Если студент презентовал материал на занятии и тема закрыта — отметь:
```
/skip_presentation <studentId>
```
`studentId` можно взять из БД (Adminer) либо из логов бота. В будущей версии будет проще.

### 6. Несколько учителей и несколько групп

- В одной группе может быть **несколько teacher'ов** (всем участникам с этим custom title). Все они получат утренний отчёт.
- Один учитель может вести **несколько групп** — в DM ему придёт отдельный отчёт по каждой.
- Никто из учителей не видит данные **чужих** групп.

## Для студента

### 1. Регистрация

1. В группе класса учитель публикует анонс с кнопкой «📚 Зарегистрироваться» (после `/open_signup`).
2. Нажми кнопку → Telegram откроет личный чат с ботом @english_reading_task_bot и автоматически отправит `/start`.
3. Бот спросит:
   - **Какую книгу читаешь?** — напиши автора и название одной строкой. Пример: `James Clear — Atomic Habits`.
   - **Сколько всего страниц в книге?** — число, например `320`.
   - **На какой странице ты сейчас?** — текущая страница (если только начинаешь — `1`).
4. Готово. Бот скажет: «Готово ✅».

### 2. Ежедневный режим

| Время | Что делает бот |
| --- | --- |
| **08:00** | Доброе утро + напоминание читать 10–15 страниц + сессия флешкарт (если есть слова на повторение) |
| **20:00** | Спрашивает новые слова за день, потом страницу |
| **23:00** | Мягкое напоминание, если ты ещё ничего не отправил |
| **00:05** | Бот закрывает день и считает прогресс |

### 3. Команды студента

| Команда | Действие |
| --- | --- |
| `/add` | Добавить новые слова **по одному** (диалоговый режим). Бот спрашивает слово → перевод → следующее слово → ... Закончить — `/done` |
| `/done` | Завершить сессию `/add` (показывает сколько слов добавил) |
| `/words` | Отправить новые слова **списком сразу**. Формат — см. ниже |
| `/page <N>` | Отметить текущую страницу. Например `/page 47` |
| `/review` | Запустить повторение сейчас (флешкарты) |
| `/book` | Сменить книгу (старые слова сохранятся) |
| `/mystatus` | Показать текущую книгу и прогресс |
| `/help` | Показать список команд |

### 4. Отправка слов через `/words` (списком)

Пиши по одному слову на строку, в формате:

```
слово — перевод
gaudy — броский, вульгарный
in-laws - родственники супруга
jerking his thumb — дёргая большим пальцем
tense: напряжённый
```

Разделители (бот пробует по очереди):
- `—` (em-dash) или `–` (en-dash) — пробелы вокруг не обязательны
- `-` (обычный дефис) — обязательно пробелы с обеих сторон (чтобы `in-laws` не разрезался)
- `:` — обязательно пробел после двоеточия

Можно ставить маркеры или нумерацию — бот их снимет:
```
• habit — привычка
1. cue — триггер
2) reward — награда
```

Строки без разделителя бот молча пропустит — не страшно.

### 5. Отправка слов через `/add` (по одному)

Удобно для мобильного:

```
Студент: /add
Бот:     Окей, добавляем по одному 👇
         Пиши слово — я попрошу перевод. Когда закончишь — /done.
Студент: gaudy
Бот:     Перевод для «gaudy»?
Студент: броский
Бот:     Записал: gaudy — броский.
         Следующее слово (или /done):
Студент: cue
Бот:     Перевод для «cue»?
Студент: триггер
Бот:     Записал: cue — триггер.
         ...
Студент: /done
Бот:     Готово. Добавил 2 слова 👍
```

### 6. Повторение слов (флешкарты, SM-2)

Когда бот присылает карточку:
1. Видишь **только английское слово** + кнопку «Показать перевод».
2. Жмёшь — появляется **слово + перевод** + две кнопки.
3. Жмёшь:
   - **✓ Знал** — слово показывается следующий раз через всё больший интервал (1 день → 3 → ~8 → ~20 → ...)
   - **✗ Не знал** — интервал сбрасывается на 1 день, ease падает

Карточки приходят:
- **Утром в 08:00** автоматически (если есть due-карточки)
- По команде `/review` в любое время

Если due-карточек больше 20, бот предложит выбрать размер сессии:
```
У тебя 47 карточек на повторение. Сколько хочешь пройти сейчас?

[20 (~10 минут)]
[Все 47 (~24 минуты)]
```

(~30 секунд на карточку.)

### 7. Что делать если...

| Ситуация | Решение |
| --- | --- |
| Опечатался в новом слове | Сейчас редактировать нельзя — пропусти, в следующий раз попадёт корректное |
| Хочу сменить книгу | `/book` в DM — бот заново спросит автора/название/страницы. Старые слова остаются, повторение продолжится |
| Не помню на какой я странице | `/mystatus` покажет последнюю отмеченную |
| Пропустил вечерний сбор | Можешь в любое время до полуночи вручную: `/words` и/или `/page <N>` |
| Сегодня прочитал больше 15 страниц | Окей. Бот не штрафует за «много», только за «ничего» |
| Пишет «Слов на повторение пока нет» | Это норма — карточки появятся через сутки после первого изучения |

## Известные ограничения MVP

- **Один студент = одна группа.** Если студент должен быть в двух группах — пока нельзя.
- **Один глобальный часовой пояс** (`Asia/Tashkent`, настраивается через `.env`). Кроны выполняются по нему для всех групп.
- **`/set_morning` / `/set_evening`** записывают время в БД, но фактический крон пока работает в глобальное расписание. Per-group расписание — в следующей версии.
- **Отправленные слова нельзя редактировать** через бот. Только через БД админом.
- **Бот использует long polling**, а не вебхуки. Если бот перезапускается посреди дня — пропущенные апдейты должны догнать его за 24 часа (лимит Telegram).
